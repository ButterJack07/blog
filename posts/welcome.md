# 欢迎来到我的博客

这是一个专门为你设计的双身份静态博客，结合了技术和音乐两个板块，不需要复杂的后端，直接就能用。

## 🎉 博客特点

- **双身份设计**：技术+音乐两个板块，分别用莫兰迪绿和暖棕色区分，既统一又有辨识度
- **Markdown支持**：所有文章都用Markdown写，自带代码高亮，写技术笔记非常方便
- **文件上传**：支持PDF、压缩包等各种文件下载，课件、笔记、资料随便放
- **第三方联动**：已经内置了你的GitHub和B站链接，侧边栏自动显示GitHub统计
- **纯静态**：不需要服务器，直接丢GitHub Pages就能上线，永远不会挂
- **响应式**：手机电脑都能完美显示

## 📝 怎么发新文章？

超级简单，三步搞定：

1. 在 `posts` 文件夹里新建一个 `.md` 文件，比如 `组成原理笔记.md`，用Markdown写内容
2. 打开 `index.html`，找到文章列表的位置，复制一个文章条目，改改标题、日期、标签
3. 刷新页面就能看到新文章了！

## 📎 怎么上传笔记文件？

把PDF、zip、课件等文件直接丢到 `files` 文件夹，然后在文章里加下载链接就行：

```html
<a href="files/计算机组成原理复习笔记.pdf" download class="text-tech-green hover:underline">
    <i class="fa fa-download"></i> 下载PDF笔记
</a>
```

图片的话丢到 `images` 文件夹，Markdown里直接写 `![图片描述](../images/xxx.jpg)` 就能显示。

## 💻 怎么加新技术项目？

在「技术作品」页面复制一个项目卡片，改改内容：
- 项目名称、描述
- 技术栈标签
- GitHub链接改成你对应的仓库地址
- 可以换个图标或者背景色区分不同类型的项目

## 🎵 怎么上传音乐？

把mp3文件丢到 `music` 文件夹，然后把音乐页面里audio标签的src改成对应的路径：
```html
<audio controls class="w-full mb-4">
    <source src="music/彩燕.mp3" type="audio/mpeg">
</audio>
```
还可以加歌词、创作背景什么的。

## 🔗 第三方联动说明

- **GitHub**：侧边栏已经自动显示你的GitHub统计数据，所有项目都可以直接链到你的仓库，地址已经填好了是 `https://github.com/ButterJack07`
- **B站**：所有视频相关的内容都可以链到你的B站空间 `https://space.bilibili.com/1453945101`，如果需要嵌入视频直接用B站的iframe分享代码就行
- 后续如果需要加网易云音乐、邮箱什么的，直接在侧边栏加链接就行

## 🚀 怎么部署上线？

直接把整个 `Blog` 文件夹推到GitHub，开启GitHub Pages，所有人都能访问了，完全免费。

如果需要自定义域名，买个域名解析一下就行。

> 有任何需要调整的地方，比如改颜色、加功能、调整布局，随时说就行。

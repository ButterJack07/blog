# ButterJack 博客

ButterJack07 的个人博客，纯静态单 HTML 文件，托管于 GitHub Pages。

https://butterjack07.github.io/blog/

## 技术栈

- **零依赖**：纯静态 HTML，CSS/JS 全部内嵌于 `index.html`
- **无框架**：不使用 npm、Vite、React 等构建工具
- **HashRouter**：`#/home` `#/music` `#/nav` `#/library` 前端路由
- **数据持久化**：localStorage（编辑模式下的链接、笔记本、章节）
- **音频**：Web Audio API + Canvas 频谱可视化
- **歌词**：标准 LRC 格式解析，支持前 3 行 JSON 元数据
- **响应式**：CSS @media 断点 768px，移动端汉堡菜单

## 配色

莫兰迪色系，低饱和度柔和配色：
- 主色：`#6366f1`（Indigo）
- 强调色：`#c97a7a`（哑光粉红，歌词高亮）
- 背景：`#f8fafc` → `#f1f5f9` → `#e8f0fe` 渐变
- 卡片：`rgba(255,255,255,0.7)` 毛玻璃效果

## 功能详情

### 音乐播放器

**播放器视图**：
- 专辑封面 / 歌曲信息 / 控制按钮（上/下一首、播放/暂停）
- 进度条拖拽 + 音量滑块
- Canvas 频谱柱状图（Web Audio API AnalyserNode）
- LRC 歌词实时滚动，当前行居中高亮（莫兰迪粉 `#c97a7a`，字号 `1.1rem`）
- 点击歌词行跳转到对应时间
- 已过行变淡（`past` 样式），当前行隐藏时间戳（`opacity:0`）

**列表视图**：
- 点击 "☰ 歌曲列表" 切换至纯列表页
- 点击歌曲直接播放，自动切回播放器视图
- 视图切换带淡入动画

**底部全局播放条**：
- 固定底部，显示当前歌曲、迷你进度条、播放控制
- 所有页面可见

**上传流程**（编辑模式）：
- 填写标题、艺术家、风格、年份
- 选择音频 / LRC 歌词 / 封面文件
- 输入 GitHub Token，直接上传到仓库对应目录
- 自动更新 `info.json` 和本地播放列表

### 有趣的东西（网页导航）

- 预设 6 个分类：工具、框架、平台、设计、博客、其他
- 分类按钮筛选
- **编辑模式**：添加新链接（标题/URL/描述/图标/分类）、删除链接
- **拖拽排序**：编辑模式下直接拖拽卡片重排，localStorage 持久化

### 知识库（图书馆）

- **书架** → **笔记本** → **章节** 三级浏览
- 每个笔记本有独立配色和章节计数
- **编辑模式**：新建/删除笔记本
- **章节编辑器**：Markdown 编辑 + 预览切换（支持 `# h1` `## h2` 标题渲染）
- 全部数据持久化到 localStorage

### 编辑模式

- **桌面端**：左上角浮动 🔧 圆形按钮
- **移动端**：侧边栏展开后右上角 🔧 按钮
- 激活后显示所有增删/编辑/拖拽控件
- 无需登录，数据仅存浏览器

### 响应式布局

- 断点：`768px`
- 侧边栏：桌面固定显示，移动端隐藏 + 汉堡菜单滑出
- 播放器：桌面左右布局（封面 + 歌词），移动端上下堆叠
- 歌词区：移动端高度缩短至 250px
- 导航网格 / 书架 / 卡片：自动调整列数

## 音乐数据

```
music/
├── tracks.json          # 音乐清单（标题、艺术家、路径等）
├── 渺小/                # 每首歌曲独立文件夹
│   ├── 黄油夹克 - 渺小.mp3
│   └── 黄油夹克 - 渺小.lrc   # 前3行JSON元数据，第4行起标准LRC
├── 彩燕/
│   ├── info.json
│   ├── 彩燕.mp3
│   └── 彩燕.lrc
└── 彩燕2025/
    └── 彩燕2025.mp3
```

- `tracks.json` 决定播放列表顺序（不上传时也有本地 fallback）
- LRC 文件标准格式：`[mm:ss.xxx]歌词内容`
- 上传新曲目自动创建文件夹和 `info.json`

## 本地预览

```bash
# Python
python -m http.server 5500

# Node
npx serve .
```

打开 `http://localhost:5500`（或对应端口），音频和歌词需要 HTTP 服务器，直接双击 `index.html` 可能因 CORS 无法加载。

## 部署

GitHub Pages：Settings → Pages → Source: **Deploy from branch** `master`, **root** `/`。

推送后等待 1-2 分钟自动生效。
